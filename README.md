# ATM Banking System - Java

## About
Console based ATM Banking System built 
using Java, JDBC and MySQL.

## Features
- Create Bank Account
- Login with Account Number and PIN
- Check Balance
- Deposit Money
- Withdraw Money
- Transaction History

## Technologies Used
- Java
- JDBC
- MySQL
- OOP Concepts

## Database Tables
- accounts
- transactions

## How to Run
1. Clone this repository
2. Create database using SQL in DatabaseConnection.java
3. Add mysql-connector JAR to build path
4. Open in Eclipse IDE
5. Run Main.java
